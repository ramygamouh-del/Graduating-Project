# 🏨 Hotel Booking Cancellation Prediction & EDA

This repository contains my graduation project (*Projet de Fin d'Études - PFE*) focused on analyzing hotel booking dynamics and predicting cancellation risks using Data Science and Machine Learning techniques.

## 📌 Overview

The dataset contains **8,568 observations** across **33 variables** for the year **2024**. The project explores operational performance across two types of establishments: a **City Hotel** and a **Resort Hotel**.

## 📊 Exploratory Data Analysis (EDA)

The exploratory analysis is structured into 4 key angles:
* **Temporal Approach:** Cross-sectional analysis covering the 2024 timeframe.
* **Spatial Approach:** Identifying guest origin cities for completed and canceled bookings.
* **Institutional Approach:** Comparative microeconomic analysis between City and Resort Hotels.
* **Performance Approach:** Business KPIs (booking counts, completion rates, cancellation rates, new guest ratios).

## 🛠️ Tech Stack

* **Programming & Modeling:** Python (`pandas`, `numpy`, `scikit-learn`, `category_encoders`)
* **Machine Learning:** Supervised classification models (Logistic Regression, Random Forest, Gradient Boosting, Support Vector Machines)
* **Business Intelligence:** Power BI (DAX measures) & Excel
